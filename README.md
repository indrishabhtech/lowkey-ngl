# lowkey - Anonymous Messaging App 👀

A Gen-Z styled anonymous messaging app. Share your link, get anonymous messages from friends - zero drama, completely free!

## 🚀 Quick Start

1. Download all 3 files:
   - `index.html`
   - `style.css`
   - `script.js`

2. Put them in the same folder

3. Open `index.html` in your browser - that's it!

## 📦 Deployment Options

### Option 1: Netlify (Easiest - Recommended)
1. Go to [Netlify](https://www.netlify.com/)
2. Sign up/login (free)
3. Drag and drop your folder with all 3 files
4. Done! You'll get a live URL like `yourapp.netlify.app`

### Option 2: GitHub Pages
1. Create a GitHub account
2. Create a new repository
3. Upload all 3 files
4. Go to Settings > Pages
5. Enable GitHub Pages
6. Your site will be live at `yourusername.github.io/repo-name`

### Option 3: Vercel
1. Go to [Vercel](https://vercel.com/)
2. Sign up/login (free)
3. Import your project
4. Deploy!

## 🎯 How It Works

1. **Create Profile**: Pick a username (e.g., "john")
2. **Get Your Link**: You'll get a unique link like `yoursite.com?u=john`
3. **Share It**: Share on Instagram, WhatsApp, wherever
4. **Receive Messages**: Friends send you anonymous messages
5. **View Inbox**: Check your messages anytime

## 📝 Technical Details

- Pure HTML, CSS, JavaScript (no frameworks)
- Uses localStorage for data persistence
- No database required
- No backend required
- Works offline after first load

## 🔒 Privacy

- Messages are stored locally in the browser
- No server storage
- No tracking
- Completely anonymous

Want to change the colors? Edit `style.css`:
- Line 9: Background gradient colors

- Line 234: Share card gradient colors

## 🐛 Troubleshooting

**Messages not saving?**
- Make sure you're using the same browser
- Check if cookies/localStorage is enabled
- Try clearing cache and reload

**Can't share on mobile?**
- Use the "Copy" button instead
- Paste the link manually
